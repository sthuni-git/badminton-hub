# 공용 대회 등록 (Vercel)

- 관리자로 로그인 → 새 대회 등록 → 포스터 여러 장 선택 또는 직접 입력.
- 포스터 한 장당 초안 한 개. 최대 20개를 한 번에 검토·등록합니다.
- JPG/PNG/WEBP, 원본 장당 20MB 이하. 브라우저에서 JPEG로 변환·압축하여 2MB 이하로 전송합니다.
- 이미지 OCR은 하지 않습니다. 대회명, 실제 개최일, 장소를 확인해 직접 입력합니다. 미확인 참가비·후원 정보는 추정하지 않습니다.
- 성공 항목은 즉시 공개되고, 실패 항목만 재시도합니다. 초안 ID를 재사용해 응답 유실 시 중복을 방지합니다. 초안은 창을 닫으면 사라집니다.

## 배포 설정

1. Vercel `badminton-hub` → Storage → Public Blob 생성/연결. 한국 이용자 대상이면 Seoul 리전을 선택합니다.
2. Production 및 Preview에 저장소를 연결합니다. 최신 SDK는 `BLOB_STORE_ID`와 Vercel OIDC 인증을 자동 사용합니다. 별도 장기 토큰은 필요하지 않습니다. 기존 `BLOB_READ_WRITE_TOKEN`도 지원합니다.
3. 프로젝트 Settings → Environment Variables에 `ADMIN_REGISTRATION_PASSWORD`를 설정합니다. 추측 불가능한 16자 이상의 새 비밀번호를 사용하세요. `VITE_` 접두사를 붙이지 말고, 코드/Git/채팅에 기록하지 마세요. Production/Preview에 설정 후 재배포합니다.
4. `/api/tournaments` GET이 JSON을 반환하는지 확인합니다. 저장소 미설정은 503, 인증 실패는 401입니다. 저장 성공을 확인하기 전에는 성공 알림을 표시하지 않습니다.

기존 클라이언트 고정 비밀번호는 서버 인증으로 대체했습니다. localStorage의 관리자 표시 여부는 권한을 부여하지 않습니다. 등록/공개 해제 시 서버 비밀번호를 검증합니다. 비밀번호는 브라우저 저장소에 저장하지 않습니다.

## 데이터와 운영

- `manual/production/records/`와 `manual/production/posters/`에 운영 데이터를 저장합니다. Preview는 `manual/preview/`로 분리됩니다.
- 사이트 GET API는 공용 등록 목록을 로드하며 60초 및 창 포커스 시 갱신합니다. 다른 기기에서도 새로고침해 확인할 수 있습니다.
- 기존 브라우저의 localStorage 등록은 그 기기에만 남습니다. 개인정보/미확인 데이터의 자동 공개를 막기 위해 자동 이관하지 않습니다. 필요 항목을 새 화면에서 검토 후 등록하세요.
- 공용 대회 삭제 버튼은 공개 해제(soft delete)입니다. 원본 JSON과 포스터는 저장소에 보존되며 기존 이미지 URL 접근까지 취소하지 않습니다. 저장소의 JSON `deleted` 값을 복원하면 다시 표시할 수 있습니다.
- Blob 저장소는 공개 자산만 저장합니다. 개인 연락처·민감정보가 포함된 포스터를 공개하지 마세요.
- 수집 데이터 JSON과 별도이므로 크롤러 갱신이나 재배포에 덮어써지지 않습니다.
- 대량 트래픽/대량 대회 데이터에서는 레코드별 Blob 조회 비용을 고려해 데이터베이스/색인 도입을 검토하세요.
